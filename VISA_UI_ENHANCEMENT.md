## 🚀 HOW TO USE

### 1. **Select a Country**
```
1. Click on "Select Destination Country" dropdown
2. You'll see organized regions with country counts
3. Select your desired country (with flag emoji)
4. Click "Check Requirements"
```

### 2. **View Visa Details**
```
✅ Visa Type: Tourist, e-Visa, Standard, etc.
✅ Processing Time: 1-30 days (varies)
✅ Fee: $25-150 (in USD)
✅ Validity: 1-10 years
✅ Stay Duration: Up to 30 days - 6 months
```

### 3. **Apply for Visa**
```
1. Fill in Personal Information
2. Enter Contact Details
3. Upload Required Documents
4. Submit Application
5. Track Status
```
