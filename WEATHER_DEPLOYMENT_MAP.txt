API ENDPOINT:
    GET /api/weather?city={city_name}
         ↓
    Flask Route Handler (app.py, line ~2320)
         ↓
    OpenWeatherMap API Call
         ↓
    Process Response & Generate Alerts
         ↓
    Return JSON with:
    ├─ Temperature, Humidity, Wind, Visibility
    ├─ Weather Description and Icon URL
    ├─ Smart Travel Alerts (8 types)
    │  ├─ Rain Alert
    │  ├─ Storm Alert
    │  ├─ Snow Alert
    │  ├─ Extreme Heat Alert (>40°C)
    │  ├─ High Heat Alert (35-40°C)
    │  ├─ Cold Alert (<0°C)
    │  ├─ Wind Alert (>40 km/h)
    │  └─ Fog Alert (<1 km visibility)
    └─ Alert Severity Level (warning/danger)
